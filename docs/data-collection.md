# 시연용 입구 데이터 수집 가이드 (팀원용)

시연할 장소 3~5곳의 주차장 입구를 직접 조사해서 앱에 넣는다. 한 곳당 30분 정도 걸린다.

## 1. 어떤 장소를 고르나

- 상가 건물이 붙어 있어서 **경사로 입구가 여러 개 연달아 보이는 곳**
- 내비가 "목적지 부근"이라고 할 때 진짜 입구가 어느 것인지 헷갈리는 곳
- 들어가는 입구와 나가는 출구가 따로 있는 곳이면 더 좋다
- 팀원 중 실제로 헤맨 적 있는 곳이 가장 좋다(기획서의 실제 사례가 됨)

후보를 정하면 단톡에 장소 이름과 지도 링크를 먼저 공유하고 겹치지 않게 나눈다.

## 2. 안전과 개인정보

- **운전 중에 촬영하지 않는다.** 동승자가 찍거나, 걸어가서 인도에서 찍는다.
- 사람 얼굴과 자동차 번호판이 크게 나오지 않게 찍는다. 나오면 나중에 모자이크한다.
- 건물 안(사유지)에 들어가지 말고 공공 도로·인도에서 찍는다.

## 3. 입구마다 기록할 것

| 항목 | 예시 | 방법 |
|---|---|---|
| 장소 이름 | ○○빌딩 | 지도 앱 이름 그대로 |
| 입구 좌표 | 37.56123, 126.92345 | 카카오맵·네이버지도에서 경사로 시작점을 길게 눌러 좌표 복사 |
| 들어가는 입구인지 | 진입 전용 / 출구 전용 / 겸용 | 표지판 확인 |
| 주로 오는 방향 | 신촌역 방향에서 서쪽으로 진행 | 내비가 보통 데려오는 방향 |
| 도로 어느 쪽 | 진행 방향 오른쪽 | |
| 몇 번째 경사로 | 오는 방향에서 두 번째 | 앞에 있는 다른 건물 경사로까지 세기 |
| 눈에 띄는 단서 | 편의점 바로 다음, 파란 간판 아래 | 운전자가 멀리서 볼 수 있는 것 |
| 헷갈리는 옆 입구 | 바로 앞 경사로는 옆 건물 △△ 주차장 | 좌표도 같이 |
| 높이 제한 | 2.3m | 입구 위 표지판 |
| 요금·운영 시간 | 10분 1,000원, 24시간 | 입구 안내판 (있으면) |

## 4. 사진 찍는 법

- **입구마다 2장**: 30~50m 앞에서 운전자 눈높이로 한 장(멀리서 알아보는 용), 입구 정면에서 한 장.
- 가로로 찍는다. 앱 카드가 가로로 넓다.
- 헷갈리는 옆 입구도 한 장 찍는다.
- 파일 이름: `장소번호-입구번호-far.jpg`, `장소번호-입구번호-near.jpg` (예: `03-1-far.jpg`)

## 5. 실측 (기획서 근거용, 가능하면)

국내에는 "입구 찾는 데 걸린 시간"만 따로 잰 통계가 없다. 우리가 직접 재면 기획서의 강한 근거가 된다.

- 처음 가는 사람이 운전(또는 동승)해서 "목적지 부근" 안내가 나온 순간부터 입구에 들어갈 때까지 걸린 시간
- 입구를 지나쳐서 다시 돌아온 적이 있는지, 몇 번인지
- 날짜, 시간대, 날씨

## 6. 올리는 곳

- 사진: 저장소 `app/src/main/assets/entrances/` 폴더 (또는 단톡에 올리면 정리해서 넣음)
- 기록: 아래 양식을 복사해서 채워 단톡에 올리거나, `entrances.json`을 직접 고친다.

```
장소: 
지도 링크: 
입구 좌표: 
진입/출구/겸용: 
오는 방향: 
도로 쪽: 
몇 번째: 
단서: 
헷갈리는 옆 입구(설명, 좌표): 
높이 제한: 
요금·시간: 
사진 파일: 
실측(시간, 지나친 횟수): 
```

## 11/10 추가된 데이터 칸

- `photoFarNight`, `photoNearNight`: 밤에 찍은 사진(선택). 밤 모드에서 우선 보여 준다. 가능하면 낮과 같은 자리에서 한 장씩 더 찍는다.
- 입구가 여러 개인 건물은 입구마다 `approachBearingDeg`(주로 들어오는 방향, 북=0·동=90)를 꼭 적는다. 앱이 달리는 방향과 가장 잘 맞는 입구를 고른다.
- `heightLimitM`: 입구 300m 전 화면에 나오고, 운전자가 넣어 둔 차 높이보다 낮으면 경고한다. 표지판 숫자 그대로 적는다.
